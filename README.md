# Canopee SDK — Python

Client SDK for a [Canopee](https://github.com/Canopee-network/canopee) node's
Unix socket: identity, storage, user records, devices, pairing, DHT, pub/sub
and capabilities — API-for-API parity with the Rust `canopee-sdk` crate.

## Install / test

```sh
pip install .
python -m unittest discover -s tests -v   # golden-vector, shape and framing tests
```

Python ≥ 3.10, no dependencies.

## Quick start

```python
from canopee_sdk import Client, BLOB

node = Client()  # $CANOPEE_APP_ROOT/.canopee/node.sock, else ~/.canopee/node.sock

oid = node.put(b"hi")              # store a blob
obj = node.get(oid)                # read it back
node.set_name(oid, "hi")
infos = node.list()                # list objects
status = node.status()             # NodeStatus(identity, objects, peers)
node.add_device("12D3KooW...", "phone2")

# typed payloads
profile = node.load_profile()
node.save_profile(profile) if profile else None

# pub/sub
sub = node.subscribe("topic")
for msg in sub:
    print(msg)
```

Errors: a `NodeResponse::Error` becomes `CanopeeError`; a missing socket becomes
`NodeNotRunningError`.

## API

Every method maps one-to-one onto a `NodeCommand`/`NodeResponse` pair of the
Rust SDK:

- **Storage**: `put`, `put_object`, `concat`, `get`, `list`, `delete_object`,
  `set_name`, `export_object`, `import_object`
- **Runtime/identity**: `status`, `identity`, `shutdown`, `dh_public_key`,
  `save_profile`, `load_profile`, `save_contact_list`, `load_contact_list`,
  `save_home_index`, `load_home_index`, `set_home_entry_shared`,
  `export_identity`, `import_identity`
- **Network/user records**: `publish_pointer`, `publish_app_pointer`,
  `resolve_app_pointer`, `resolve_pointer`, `claim_username`,
  `resolve_username`, `show_username`, `resolve_profile`
- **Devices/pairing**: `device`, `device_list`, `resolve_owner_device`,
  `add_device`, `remove_device`, `initiate_pairing`, `complete_pairing`,
  `sync_from_peer`, `sync_device_list`
- **Networking/DHT**: `dial`, `listen_via_relay`, `publish`, `peers`,
  `relay_reservations`, `find_providers`, `fetch_object`, `announce`,
  `put_object_public`, `share_object`, `subscribe`
- **Capabilities**: `grant_capability`, `list_capabilities`,
  `revoke_capability`, `check_capability`, `check_access`
- **Serve sessions**: `start_serve_session`, `stop_serve_session`

Package layout:

- `canopee_sdk/_codec.py` — bincode 1.x legacy codec, the `NodeCommand`/
  `NodeResponse` variant tables (golden-fixture-tested), socket framing.
- `canopee_sdk/_types.py` — typed model (dataclasses) and lossless
  typed ↔ shape conversion.
- `canopee_sdk/_client.py` — `Client` and `Subscription`.

## Wire contract

Frame = `u32 LE length` + payload, over a Unix socket. Payloads are **bincode
1.x legacy**: little-endian fixints, `u32` enum tags, `u64` length prefixes,
`Option` = one tag byte, fixed arrays raw, map keys sorted. The golden fixture
`tests/fixtures/golden.json` (generated by `canopee-sdk`'s
`tests/golden_vectors.rs`) pins every encoder/decoder to the exact bytes the
node speaks; `python -m unittest` re-asserts all vectors in both directions.
